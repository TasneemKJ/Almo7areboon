# Juice iteration 1: Role-weighted recruit arrival

## Current design review — 2026-10-08

This concrete alternative review expands the earlier short implementation brainstorm. It was written during current review; it does not claim these detailed alternatives were recorded before the source work.

**Identify:** accepted spawn events needs a readable physical reply. **Define:** attach the reply to the event-bound recruit sprite; preserve the existing rules, art, controls and save formats. **Explore:** the twenty concrete alternatives below. **Act:** retain the selected small response in the existing renderer. **Look back:** behavior counterchecks and source integration checks support this implementation; mandatory viewed mobile/browser acceptance is still pending because Chromium cannot start in this environment.

**Who:** the phone strategist watching live combat. **What:** Role-weighted recruit arrival. **Where:** the event-bound recruit sprite. **When:** accepted spawn events, then a finite reply. **Why:** strengthen cause and effect without another menu, toast or persistent panel.

| # | Concrete alternative | Decision and reason |
|---|---|---|
| 1 | Role-weighted squash and lift on the real recruit | Selected: tells light and heavy arrivals apart without changing collision positions |
| 2 | Recruit leans forward from the gate | Deferred: Would duplicate the walking gesture |
| 3 | Heavy recruit shoulder drops on entry | Deferred: Needs new shoulder articulation for painted atlases |
| 4 | Ranged recruit checks their weapon | Deferred: Requires new authored pose frames for every chapter |
| 5 | Infantry salutes on deployment | Deferred: Adds acting delay unrelated to immediate combat |
| 6 | Mounted recruit stamps a hoof | Deferred: Needs role-specific hoof anchors |
| 7 | Arrival ribbon curls around the recruit | Deferred: Could obscure team silhouette |
| 8 | Recruit’s halo flares once | Deferred: Current spawn flare already provides light |
| 9 | Gate cloth snaps when a troop leaves | Deferred: Competes with the existing order pennant |
| 10 | Small camera nudge follows each deployment | Deferred: Too frequent for a one-thumb battle |
| 11 | New troop rises from a portal | Deferred: Does not fit the current fictional settlement |
| 12 | Recruit dust bursts outward | Deferred: Current spawn dust already does this |
| 13 | Body opacity eases from transparent | Deferred: Can imply invulnerability or incomplete spawning |
| 14 | Birth shadow grows under the unit | Deferred: Contact prints are a clearer separate ground witness |
| 15 | Small brass role glyph floats upward | Deferred: Adds another floating UI label |
| 16 | Recruit name appears briefly above them | Deferred: Name text would cover combat |
| 17 | Entry scale depends on troop cost | Deferred: Cost should not masquerade as visual body strength |
| 18 | Enemy arrivals get a sharper spring | Deferred: Team tint already supplies side identity |
| 19 | Rebuilt sprites replay the arrival | Rejected: a redraw is not a new deployment |
