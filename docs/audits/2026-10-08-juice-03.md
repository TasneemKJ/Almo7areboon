# Juice iteration 3: Ballistic projectile glow continuity

## Current design review — 2026-10-08

This concrete alternative review expands the earlier short implementation brainstorm. It was written during current review; it does not claim these detailed alternatives were recorded before the source work.

**Identify:** live ballistic projectile flight needs a readable physical reply. **Define:** attach the reply to the same sampled curve as the visible shot; preserve the existing rules, art, controls and save formats. **Explore:** the twenty concrete alternatives below. **Act:** retain the selected small response in the existing renderer. **Look back:** behavior counterchecks and source integration checks support this implementation; mandatory viewed mobile/browser acceptance is still pending because Chromium cannot start in this environment.

**Who:** the phone strategist watching live combat. **What:** Ballistic projectile glow continuity. **Where:** the same sampled curve as the visible shot. **When:** live ballistic projectile flight, then a finite reply. **Why:** strengthen cause and effect without another menu, toast or persistent panel.
