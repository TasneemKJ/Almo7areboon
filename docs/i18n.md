# Arabic and English: how the game speaks

Almo7areboon ships in English and Arabic. One language per screen: in Arabic mode no English word appears outside
the language picker, and in English no Arabic appears outside it (and outside deliberate bilingual titles such as
the name «المحاربون · Almo7areboon»).

## Mechanics (`src/game/locale.ts`, `src/ui/i18n.ts`, `src/app/language-boot.ts`)

- Write every player-facing string as an inline pair where it is shown: `tr('Battle time', 'وقت المعركة')`.
  Screen readers count: `aria-label`, `title`, `alt` and `role="status"` text are player-facing too.
- Call `tr()` while rendering, **never at module top level**. A table of strings becomes pairs
  (`{en:'First Fires', ar:'النيران الأولى'}`) or a function, picked at render time.
- Numbers inside text go in `n(…)` from `src/ui/i18n.ts` (`<bdi dir="ltr">…</bdi>`). Attributes take the plain value.
  Digits stay Western (0-9), as on Levantine shop signs and phones; `toLocaleString('en-US')` stays.
- Plurals: `plural(count, ['card','cards'], ['بطاقة','بطاقتان','بطاقات','بطاقة'])` (one, two, 3-10, 11+), or
  phrase around the count ("Cards: 3" / "البطاقات: 3") when a plural would be awkward.
- The language is chosen at boot (saved choice, else the device language, else English), sets `<html lang dir>`,
  and changes only through Preferences → Language, which saves and reloads.
- Layout follows `dir`: use logical CSS (`margin-inline-start`, `inset-inline-end`, `text-align:start`). The
  battlefield itself (your gate on the left, the rival on the right) is a picture and is not mirrored.
- Internal ids, save fields and CSS classes never change; only what is shown.
- Tests run in English by default. A test that switches to Arabic calls `setLang('ar')` and restores `setLang('en')`.

## Voice

Modern Standard Arabic with the warmth of a Levantine folk tale: short, plain, spoken lines, like a storyteller
(حكواتي), not a legal text. Imperatives for buttons (ابدأ، تقدّم، اجمع). Full tashkeel only where a word would be
misread; a shadda where it helps (سريّة، المؤونة). No machine-literal translation: say what the English means.
