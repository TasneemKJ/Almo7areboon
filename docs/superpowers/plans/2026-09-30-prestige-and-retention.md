## Review Focus

- Ownership loss while a preview is open: checking before confirmation must prevent stale mutation/write and recovery must stay above any result/picker restoration. Task 1 pins the guard interop; Task 2 proves the actual route.
- Malformed v4 rank/choice/best fields: corrupt optional fields must not manufacture rank three, erase valid rank, or reopen paid seals. Task 1 pins independent normalization and round trips.
- Changed final-`next` callers: old campaign/browser scripts and legacy pending wins must still have a reachable authoritative reset route through `prestige`; ordinary continuation and terminal return remain intact. Both tasks update their callers and regression gates.
- Switching a ready preparation versus drafting a preview: only an accepted ready action changes active effects; the draft/cancel must retain receipt, current effects, and wallets. Task 1 tests state invariants; Task 2 tests DOM focus/copy/return.
- Late evolution can yield repeated zero-income losses: legal replay may recover progression, so a script must distinguish timeout/policy failure from a universal economy wall. Task 1 uses actual outcomes and separated ledgers; Task 2 keeps existing advice/continuation usable.
